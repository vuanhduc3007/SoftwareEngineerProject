# Library Management System

A Windows desktop application for a librarian to manage books and members, check books out and return them, review loan status and reports, and export loan history to CSV. The planned stack is Python, Tkinter, and a local SQLite database.

## Project setup

- Python 3.10 or later
- Tkinter and SQLite from the Python standard library
- No third-party runtime dependencies are currently required

Create and activate a virtual environment if desired:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

The application entry point will be documented here when the app shell is added. Sprint 1 requirements and book-catalog acceptance checks are in [docs/requirements-and-acceptance.md](docs/requirements-and-acceptance.md).
